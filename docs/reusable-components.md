# Reusable Components Catalog

## Common Components
- `Sidebar` (`components/common/Sidebar.jsx`): Responsive navigation with module numbered tags, active indicators, mobile collapsible drawer.
- `Header` (`components/common/Header.jsx`): Global search, system status indicator, quick actions, mobile toggle menu.
- `KpiCard` (`components/common/KpiCard.jsx`): Reusable summary statistic card with trend, icon, accent colors.
- `DataTable` (`components/common/DataTable.jsx`): Reusable table featuring sorting, pagination, global filter, empty state, and column action hooks.
- `StatusBadge` (`components/common/StatusBadge.jsx`): Standardized colored pill tags for all 10 module statuses.
- `Modal` (`components/common/Modal.jsx`): Accessible backdrop-dismissible dialog with header, scrollable body, and sticky actions footer.
- `Drawer` (`components/common/Drawer.jsx`): Slide-over panel for rich detailed inspections.
- `FormField` (`components/common/FormField.jsx`): Label, input, helper text, and validation error wrapper.
- `Toast` (`components/common/Toast.jsx`): Notification snackbar for success, error, and warnings.
- `ConfirmDialog` (`components/common/ConfirmDialog.jsx`): Standard confirmation prompt for irreversible actions.
